# ChatPort

**挑选对话，迁移到新账号，并确认它们已保存。**

[English](README.md) · [下载 Chrome 扩展](https://github.com/stors789/chatgpt-migrator/releases/latest)

ChatPort 是 Chrome 浏览器扩展，通过分享链接和继续对话，把选中的对话复制到你的另一个 **ChatGPT 个人账号**。原账号用普通窗口，新账号用无痕窗口，登录会话相互隔离。**使用时无需终端、Node.js、API Key，也不用复制 Cookie。**

## 安装

1. 从 [Releases](https://github.com/stors789/chatgpt-migrator/releases/latest) 下载 `chatport-extension-v0.2.1.zip`，解压到准备长期保留的文件夹。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角「开发者模式」，点击「加载已解压的扩展程序」，选中包含 `manifest.json` 的解压文件夹。
3. 进入 ChatPort 的「详情」，开启「允许在无痕模式下运行」。扩展需要用它访问新账号，同时保持两个账号的登录相互隔离。
4. 在 Chrome 的扩展菜单中固定 ChatPort，点击扩展图标即可打开工作台。

当前版本以本地加载的形式提供，尚未上架 Chrome 应用商店。请保留解压文件夹。更新时覆盖同一个文件夹里的文件，再在扩展管理页点「重新加载」。卸载会删除扩展的本机记录，请先下载迁移凭证。

## 迁移

1. 点「原账号 · 普通窗口」。如果尚未登录，就按平时的方式登录原账号。
2. 点「新账号 · 无痕窗口」，正常登录另一个账号。两个窗口均选择 **Personal／个人空间**，并保留窗口。
3. 回到 ChatPort，点「检查账号」，确认显示的两个账号正确，再「加载对话」。列表包括常规、归档和可访问的项目对话。
4. 按标题、日期、项目和迁移状态筛选，预览并勾选对话。切换筛选后，已选内容仍会保留。
5. 检查追加的消息和间隔，确认了解分享链接的可见范围，再点「迁移已选对话」。批量执行期间保持工作台打开；可以点「完成当前对话后暂停」。
6. 查看凭证。如果显示「待检查」，点「重新核验，不重复发送」。也可以粘贴在新账号中找到的 `https://chatgpt.com/c/...` 副本链接再核验。
7. 下载凭证。确认副本后，可自行到 ChatGPT「设置 → 数据控制 → 分享链接」撤销原账号的分享。原对话会保留。

关闭或刷新工作台会中断执行。下次打开时，已进入接收阶段的记录会变成「待检查」，不会自动重复发送。重启 Chrome 后，需要重新打开两个账号窗口，新账号也需要重新登录：全部无痕窗口关闭后，无痕登录不会保留。迁移凭证仍保存在扩展的本机存储中。

## 为什么改成扩展？

Google 官方说明会拒绝[由软件自动化控制的浏览器登录](https://support.google.com/accounts/answer/7675428?hl=zh-Hans)。0.2 版本直接操作正常 Chrome 中的 ChatGPT 会话，不使用自动化浏览器登录、不操作 Google 登录页，也不隐藏自动化特征或解决验证挑战。请使用该 ChatGPT 账号平时的登录方式。

## 什么才算「已核验」？

分享前，用 SHA-256 记录当前分支可见的用户和助手文本的摘要。接收时，追加你填写的消息和唯一的 `[ChatPort:…]` 标记。以下条件必须全部成立：

- 新对话 ID 存在，且不同于原对话 ID。
- 新账号的已保存、未归档历史列表中存在该 ID。
- 读取时返回同一 ID，且对话可编辑。
- 恰好一条用户消息完整匹配迁移标记。
- 标记之前的原有文本，在角色、顺序、内容和条数上均一致。

仅出现输入框或新链接，不会判为成功。文本缺失、账号错误、标记缺失、限流和不确定的结果均会阻止核验通过。有限的持久化检查不会重新发送消息，执行中也会再次核对账号身份。

图片、附件、生成文件、工具结果和历史替代分支需要另外检查。含媒体的消息会标注。项目对话会成为新账号里的普通对话，项目名称、指令、组织关系和项目文件不会重建。订阅、记忆、自定义 GPT 和账号设置不在迁移范围内；不支持 Business／Enterprise／Edu 跨空间迁移。

## 权限与隐私

- `https://chatgpt.com/*`：在绑定的 ChatGPT 标签页内读取选中的列表和对话、生成分享链接并接收副本。
- `scripting`：在这些标签页内执行迁移操作。
- `storage`：把凭证和绑定的标签页 ID 存在本机，不使用浏览器同步存储。
- 「允许在无痕模式下运行」：访问新账号会话。工作台与凭证仍在普通扩展环境中。

没有本地 HTTP 服务、云端后台、统计追踪、Cookie 权限、调试器权限或 Google 网站权限。登录令牌只在相应的 ChatGPT 标签页内使用，不会返回工作台。进度记录保存标题、分享链接、文本摘要和标记消息，不保存原始对话正文。预览内容仅在显示时存在工作台内存中。下载的凭证可能包含敏感标题和分享链接，请妥善保管。

## 开发与测试

只有从源码构建和测试时才需要 Node.js 22 或更新版本：

```sh
npm ci
npm run build
npm run check
npm test
npm run browser:install
npm run test:e2e
```

构建后加载 `dist/` 文件夹。运行代码使用浏览器原生接口，Playwright 仅用于开发测试。

自动测试在 Chromium 中加载真正的 Manifest V3 扩展，通过普通／无痕窗口和**虚构的 ChatGPT 接口响应**验证完整流程。测试不登录真实账号；真实双账号兼容性仍需人工试迁移，不能把自动测试通过当成网页私有接口永远兼容的保证。

旧的 Node／Playwright 版本保留在 `v0.1.0` Git 标签中。0.2 不读取旧的 `~/.chatport` 目录；凭证格式与 SHA-256 核验规则保持一致。
